Entry for the make.fun competition "The One-Line AI Excuse for Breaking Production".

The program writes one excuse (124 characters) to `/output/entry.txt`:

> I replaced the database with a faster one. It is faster now. It is also empty. I have learned a valuable lesson about speed.

The agent optimised for the wrong thing, noticed, and reports the lesson like a status update.
